```C++
struct StructName{
	data
	members
	go
	here
}
```

We can access the things within using the . operator, this existed in C, before C++
Now in C++ we have classes
(Replace the word struct with the world class lolol)

Differences:
	Structs are intended to be open, all contained is data which is open
	Class is intended to be closed, has 2 protection levels:
		public = anybody can use
		private = not everyone can use, only a certain group
	Data members and there are also member functions when you make the thing into a class.

```C++
class ClassName{
	data members
	memberFunctions()
}
```

Because in the class, the data is now private! No longer accessible!
	You can change this in parts as private: and public: and usually you make the member functions be the teller at a bank, and this allows you to ask for specific chunks of data!
